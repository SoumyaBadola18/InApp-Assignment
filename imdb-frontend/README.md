Frontend
--------

1. Install Node.js (if not already installed):

   Download from: https://nodejs.org/

2. Navigate to the frontend folder:

   cd imdb-frontend

3. Install frontend dependencies:

   npm install

4. Start the frontend app:

   npm start

   This will start the frontend on: http://127.0.0.1:3000

   Make sure the Flask backend is also running on http://127.0.0.1:5000

5. Logging into the App:

   - Use username: `admin`
   - Use password: `password123`

   The app will use your JWT token to make authenticated API calls.
